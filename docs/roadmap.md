# 16-week cumulative roadmap

## Weeks 1-3 — model/application fundamentals
- W1: Phase 00/01 — API boundary + Transformer mechanics
- W2: Phase 02/03 — tokens, sampling, inference metrics, context engineering
- W3: Phase 04 — strict tool calling and failure handling

## Weeks 4-6 — retrieval and tools
- W4: baseline RAG with citations and retrieval tests
- W5: hybrid retrieval, rerank, metadata filters, retrieval ablations
- W6: tool authorization model, MCP concepts and tool-contract hardening

## Weeks 7-10 — agent runtime
- W7: explicit single-agent loop and termination policy
- W8: Agents SDK implementation and tracing comparison
- W9: durable graph/checkpoint/human approval
- W10: MCP server/client integration

## Weeks 11-13 — production discipline
- W11: state, async jobs, checkpoint/resume
- W12: 100+ golden cases and CI regression
- W13: prompt injection, least privilege, secrets and human approval

## Weeks 14-16 — capstone
- W14: PEFT/SFT/DPO decision experiment
- W15: multi-agent/n8n only where measured benefit exists
- W16: Personal Engineering Research Agent acceptance

The capstone must reuse Phase 1 abstractions instead of replacing the project with a new demo.
