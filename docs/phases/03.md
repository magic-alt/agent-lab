# Phase 03 — context engineering

## Goal
Treat context selection as an explicit, testable subsystem.

## Tasks
- Define context items with priority and source ids.
- Pack under a fixed character budget.
- Prefer higher priority evidence, while preserving original order in the final packed context.
- Emit selected/dropped ids in the trace/eval result.

## Acceptance
- Packing is deterministic.
- Budget is never exceeded.
- A regression dataset covers irrelevant/noisy context cases.
