# Phase 02 — tokens, sampling and inference

## Goal
Connect text -> token count -> logits -> sampling to practical latency/cost reasoning.

## Tasks
- Count tokens using tiktoken when installed.
- Implement numerically stable softmax.
- Compare temperature 0.2 / 0.7 / 1.2 on fixed logits.
- Capture deterministic results with a random seed.

## Acceptance
- Sampling probabilities sum to 1.
- Temperature changes entropy in the expected direction.
- Token counting fails clearly when the optional tokenizer dependency is missing.
