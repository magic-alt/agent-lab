# Phase 04 — structured tools

## Goal
Build a safe, testable manual tool loop before adopting a higher-level agent runtime.

## Tasks
- Define strict JSON-schema tools.
- Validate arguments locally.
- Implement deterministic calculator/text/file tools.
- Return execution errors as structured tool results.
- Set a hard `max_steps` termination limit.

## Acceptance
- Invalid/unknown tools never execute arbitrary code.
- File reading is jailed to an explicit root directory.
- Calculator rejects unsupported AST nodes.
- Tool loop handles a model tool call followed by a final text response in an offline test.
