# Phase 00 — LLM API quickstart

## Goal
Own the model API boundary: configuration, request, latency, output and trace.

## Tasks
- Configure API key/model through environment variables.
- Send one Responses API request.
- Record elapsed time and response metadata locally.
- Add one failure-path test with an injected fake client.

## Acceptance
- `agent-lab phase00 "..."` works with a configured model.
- No API secret appears in logs or committed files.
- Model calls are isolated behind `OpenAIResponsesProvider`.
